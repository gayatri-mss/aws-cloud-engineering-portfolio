# AWS Cloud Engineering Portfolio

This repository showcases two cloud computing projects completed as part of COMP4349: Cloud Computing at the University of Sydney.

## Scalable AWS Image Annotation Application

Deployed a scalable Flask web application on AWS using an EC2 Auto Scaling Group and Application Load Balancer. Integrated Amazon S3 for image storage, Amazon RDS MySQL for metadata persistence, and S3-triggered AWS Lambda functions for thumbnail generation and AI-powered image captioning using the Google Gemini API.

**Key AWS services:** EC2, Auto Scaling, Application Load Balancer, VPC, S3, Lambda, ECR, RDS MySQL and IAM.

The project folder includes the deployment report and a demonstration video.

## AWS Cloud Deployment | Image Captioning Web Application

Deployed a Flask web application on Amazon EC2, integrating Amazon S3 for image storage and Amazon RDS MySQL for caption persistence, with Google Gemini API integration for image caption generation. Configured a custom VPC with public and private subnets and IAM role-based permissions for EC2 access to S3.

**Key AWS services:** EC2, S3, RDS MySQL, VPC and IAM.

The project folder includes the deployment report and a demonstration video.

## About

These projects demonstrate practical experience with AWS deployment, cloud infrastructure, networking, access controls, serverless processing and troubleshooting. Both were completed as individual university coursework projects in the AWS Academy learning environment.
